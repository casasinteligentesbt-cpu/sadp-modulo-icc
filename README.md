# sadp-modulo-icc

Proyecto de seguridad ciudadana para la **provincia de Sullana (Piura, Perú)**: videovigilancia, drones, analítica y respuesta coordinada de autoridades.

- [02 – Concepto preliminar del proyecto](docs/02-concepto-proyecto-seguridad.md): componentes, fases y financiamiento.
